2. Hierarquia de Títulos e Listas
 
- Reforçar a estrutura interna do conteúdo para não entregarem uma página "vazia".
1) Proposta: Dentro da <section> de conteúdo, obrigatoriamente usar um <h2> (subtitulo) e uma <ul> com <li> (lista de tópicos).
2) Exemplo:
  <section>
    <h2>Título da Página</h2>
    <ul>
      <li>Tópico 1</li>
      <li>Tópico 2</li>
      <li>Tópico 3</li>
    </ul>
  </section>
